# اتجاه المنتج — أصول المصممين

## ما هذا؟
**فيد اكتشاف أصول تصميمية** بأسلوب Pinterest: تصفّح بصري إدماني، دبابيس بارتفاعات متغيّرة، والصورة أولاً — مخصّص لملفات المصممين (صور، ستيكرات، ملحقات، أفكار) بالهوية البنفسجية وواجهة عربية RTL.

هذه **معاينة ويب** (GitHub Pages) لتجربة الواجهة — **وليست التطبيق النهائي**. الهدف النهائي تطبيق SwiftUI على iOS.

## الشعور المطلوب
- مثل Pinterest: شبكة masonry، صورة تملأ الدبوس، عنوان وتصنيف خفيفان أسفلها
- زر حفظ فوق الوسائط (٤٤×٤٤)
- كتالوج متماسك: كل معاينة تطابق العنوان العربي والنوع (لا صور عشوائية)
- بحث سريع + شرائح تصفية + تفاصيل مع تنزيل/حفظ ثابتين + تبويب المكتبة/المحفوظات

## التصنيفات
| التصنيف | المعنى | شكل المعاينة |
|---------|--------|--------------|
| **صور** | خلفيات وتدرجات وأنسجة | تدرجات / ملمس بصري |
| **ستيكرات** | ملصقات جاهزة للقص واللصق | رسم على خلفية منقطة |
| **ملحقات** | إطارات، شارات، أيقونات، شبكات | إطار / شارة / حزمة أيقونات |
| **أفكار** | مودبوردات وأفكار بوست/ستوري/كوفر | بطاقة فكرة مع العنوان |

## مسار المستخدم
1. **تصفح** — فيد masonry باختلاف ارتفاعات (عمودي / مربع / أفقي)
2. **فلتر / بحث** — شرائح أو «ابحث عن صور، ستيكرات، ملحقات…»
3. **اكتشاف بالبحث** — اقتراحات أثناء الكتابة، معاينات أصول، شرائح تصفية ذكية، وإنقاذ عند لا نتائج؛ يدعم `?q=`
4. **تفاصيل** — معاينة كبيرة + تنزيل + حفظ
5. **المحفوظات** — نفس أسلوب الدبابيس للعناصر المحفوظة

## بحث المكتبة
يطابق العنوان، الوسوم، نوع الأصل (صور/ستيكرات/ملحقات/أفكار)، الصيغة، النسبة، وكلمات مجاني/مدفوع — مع تطبيع عربي ومطابقة جزئية.
