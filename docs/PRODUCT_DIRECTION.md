# اتجاه المنتج — أصول المصممين

## هدف التطبيق
مكتبة أصول رقمية للمصممين وصنّاع المحتوى باللغة العربية: خلفيات، ستيكرات، ملحقات واجهة، وأفكار محتوى جاهزة للاستخدام أو الإلهام. التركيز على **تصفح سريع وواضح** حيث العنوان والصورة والتصنيف متوافقون دائماً.

## التصنيفات الأربعة
| التصنيف | المعنى | شكل المعاينة |
|---------|--------|--------------|
| **صور** | خلفيات وتدرجات وأنسجة | تدرجات / ملمس بصري مع عنوان على الوسائط |
| **ستيكرات** | ملصقات جاهزة للقص واللصق | رسم دائري على خلفية منقطة |
| **ملحقات** | إطارات، شارات، أيقونات، شبكات تخطيط | إطار / شارة / حزمة أيقونات |
| **أفكار** | مودبوردات وأفكار بوست/ستوري/كوفر | بطاقة مستند أو لوحة فكرة مع العنوان |

## مسار المستخدم
1. **تصفح** — شبكة المكتبة مع رؤوس أقسام عند اختيار «الكل»
2. **فلتر** — شرائح التصنيف (صور / ستيكرات / ملحقات / أفكار) أو البحث بالعنوان والوسوم
3. **تفاصيل** — نفس المعاينة المتماسكة + الوسوم + مشابه من نفس النوع
4. **حفظ / تنزيل** — حفظ للمحفوظات، أو تنزيل (العناصر المقفلة تُعلَن بوضوح)
